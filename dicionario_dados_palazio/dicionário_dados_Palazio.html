Dicionário de Dados - Palazio del Chef

Documentação oficial de metadados e modelagem do sistema Palazio del Chef.

Este dicionário descreve o modelo conceitual. Por isso, as chaves estrangeiras não aparecem aqui: os vínculos entre as entidades são representados pelas relações do DER e serão detalhados no modelo relacional.

ATENDENTE

Atributo Descrição Regra de negócio associada
id_atendente Identifica de forma única cada atendente cadastrado no sistema. Deve ser único e obrigatório para cada atendente.
nome_atendente Nome utilizado para identificar o atendente cadastrado no sistema. Deve ser obrigatório para o cadastro do atendente.

MESA

Atributo Descrição Regra de negócio associada
nmr_mesa Número que identifica cada mesa no estabelecimento. Deve ser único, obrigatório e corresponder a uma mesa existente no estabelecimento.

PEDIDO

Atributo Descrição Regra de negócio associada
Num_pedido Número que identifica exclusivamente cada pedido no sistema. Deve ser único e obrigatório. O número é gerado pelo sistema e não deve ser reutilizado.
data_hora_pedido Registra a data e o horário em que o pedido foi realizado. Deve ser preenchida automaticamente pelo sistema no momento do registro do pedido.
maioridade_confirmada Indica se o atendente confirmou a maioridade do cliente ao registrar bebida alcoólica no pedido (sim ou não). Obrigatório, com valor inicial "não". Deve ser "sim" quando o pedido tiver bebida alcoólica. É apenas uma marcação: nenhum dado do documento do cliente é armazenado.

ITEM DO PEDIDO (relação "Possui": Pedido x Produto)

Atributo Descrição Regra de negócio associada
qt_produto Quantidade do produto solicitada no pedido. Deve ser um número inteiro maior que zero.
preco_unitario Preço do produto no momento em que foi pedido. Deve ser copiado do preço atual do produto no registro do item e não muda se o preço do produto for alterado depois. Não pode ser negativo.
status Situação do item dentro do pedido (por exemplo, ativo ou cancelado). Deve ser obrigatório. Um item cancelado não entra no valor total a pagar.
motivo_cancelamento Motivo pelo qual o item foi cancelado. Opcional. Deve ser preenchido apenas quando o item for cancelado.
data_hora_cancelamento Data e horário em que o item foi cancelado. Opcional. Deve ser preenchida automaticamente apenas quando o item for cancelado.

PRODUTO

Atributo Descrição Regra de negócio associada
codigo_produto Código que identifica exclusivamente cada produto cadastrado no sistema. Deve ser único e obrigatório para cada produto.
nome_produto Nome utilizado para identificar o produto cadastrado no sistema. O preenchimento é obrigatório.
preco_atual Valor monetário atual do produto. Deve ser informado e não pode ser negativo.
limite_diario Quantidade máxima de porções do produto que podem ser vendidas por dia. Opcional: quando não preenchido, o produto não tem limite diário. Quando as vendas do dia atingirem o limite, o produto fica indisponível para novos pedidos.
bebida_alcoolica Indica se o produto é uma bebida alcoólica (sim ou não). Obrigatório. Produtos marcados como alcoólicos só podem ser vendidos a maiores de 18 anos, e o atendente deve conferir a maioridade antes de registrar o item no pedido.

SETOR

Atributo Descrição Regra de negócio associada
id_setor Número que identifica cada setor dentro do estabelecimento. Cada setor deve possuir um identificador único e obrigatório.
nome_setor Nome do setor responsável pela preparação ou atendimento dos produtos. Os setores cadastrados no projeto são Bar e Cozinha. Cada setor deve possuir um nome obrigatório.

PAGAMENTO

Atributo Descrição Regra de negócio associada
id_pagamento Identificador único de cada pagamento registrado no sistema. Deve ser único e obrigatório para cada pagamento.
data_hora_pagamento Registra a data e o horário em que o pagamento foi realizado. Deve ser registrada para cada pagamento concluído.
valor_pago Valor correspondente ao pagamento registrado. Deve ser maior que zero. Um pedido pode ter vários pagamentos (divisão da conta), e a soma deles não deve ultrapassar o valor total devido pelo pedido.

FORMA_PAGAMENTO

Atributo Descrição Regra de negócio associada
id_forma_pagamento Identifica de forma única cada forma de pagamento aceita pelo estabelecimento. Deve ser único e obrigatório.
descricao Nome da forma de pagamento, como dinheiro, crédito, débito ou Pix. Obrigatória e sem repetição. Todo pagamento deve usar uma forma de pagamento cadastrada.

NOTA_FISCAL

Atributo Descrição Regra de negócio associada
id_nota_fiscal Identifica de forma única cada registro de nota fiscal no sistema. Deve ser único e obrigatório.
numero_nota Número do cupom ou nota fiscal emitido. Obrigatório. A emissão é feita por sistema externo; o banco apenas armazena os dados.
serie Série da nota fiscal emitida. Obrigatória.
data_emissao Data em que a nota fiscal foi emitida. Obrigatória. A nota é registrada depois da emissão, e não impede o registro do pagamento.
valor_total Valor total que consta na nota fiscal emitida. Obrigatório e maior que zero.
chave_acesso Chave de acesso que identifica a nota fiscal perante o órgão fiscal. Obrigatória e única.

ESTOQUE

Atributo Descrição Regra de negócio associada
id_estoque Identifica exclusivamente cada registro de estoque. Deve ser único e obrigatório.
qt_disponivel Indica a quantidade disponível do produto em estoque. Deve ser um número inteiro igual ou superior a zero. Quando não houver unidades disponíveis, o valor deve ser zero.
