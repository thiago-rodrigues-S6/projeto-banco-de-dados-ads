Dicionário de Dados - Palazio del Chef

Documentação oficial de metadados e modelagem do sistema Palazio del Chef.

ATENDENTE

Atributo Descrição Regra de negócio associada
id_atendente Identifica de forma única para cada atendente cadastrado no sistema. Deve ser único e obrigatório para cada atendente.
nome_atendente Nome utilizado para identificar o atendente cadastrado no sistema. Deve ser obrigatório para o cadastro do atendente.

MESA

atributo Descrição Regra de negócio associada
numero_mesa Número que identifica cada mesa no estabelecimento. Deve ser único, obrigatório e corresponder a uma mesa existente no estabelecimento.

PEDIDO

Atributo Descrição Regra de negócio associada
numero_pedido Número que identifica exclusivamente cada pedido no sistema. Deve ser único e obrigatório. O número é gerado pelo sistema e não deve ser reutilizado.
data_pedido Registra a data e o horário em que o pedido foi realizado. Deve ser preenchida automaticamente pelo sistema no momento do registro do pedido.
forma_pagamento Forma utilizada para realizar o pagamento do pedido. Pode ser dinheiro, crédito, débito ou pix. Pode permanecer sem preenchimento enquanto o pedido estiver aberto e deve ser informada quando ele for quitado.
id_atendente Identifica o atendente responsável pelo registro do pedido. É obrigatório e deve corresponder a um atendente cadastrado.
numero_mesa Identifica a mesa associada ao pedido. É obrigatório e deve corresponder a uma mesa cadastrada no estabelecimento.

PRODUTO

Atributo Descrição Regra de negócio associada
código_produto Código que identifica exclusivamente cada produto cadastrado no sistema. Deve ser único e obrigatório para cada produto.
nome_produto Nome utilizado para identificar o produto cadastrado no sistema. O preenchimento é obrigatório.
preco_atual Valor monetário atual do produto. Deve ser informado e não pode ser negativo.
qt_estoque Quantidade disponível do produto em estoque. Deve ser um número inteiro igual ou superior a zero. Quando um produto for cadastrado sem estoque disponível, a quantidade será zero.
id_setor Identificador do setor responsável pela preparação ou atendimento do produto. Deve corresponder a um setor cadastrado, como Bar ou Cozinha.

SETOR

Atributo Descrição Regra de negócio associada
id_Setor Número que identifica cada setor dentro do estabelecimento. Cada setor deve possuir um identificador único e obrigatório.
nome_setor Nome do setor responsável pela preparação ou atendimento dos produtos. Os setores cadastrados no projetoa são Bar e Cozinha. Cada setor deve possuir um nome obrigatório.
